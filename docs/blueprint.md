# **App Name**: TNPSC Ace

## Core Features:

- Class-wise MCQ Tests: Offer multiple-choice question (MCQ) tests organized by academic class, covering the TNPSC exam syllabus.
- Subject-wise MCQ Tests: Provide MCQ tests categorized by subject, allowing focused practice on specific areas of the TNPSC exam.
- Previous Year Question Papers: Make available past TNPSC question papers in an MCQ format, facilitating familiarization with the exam pattern.
- Score Tracking: Track user scores on each test, providing insights into strengths and weaknesses.
- Menu Bar Navigation: Implement a user-friendly menu bar for easy navigation between class-wise tests, subject-wise tests, and previous year papers.

## Style Guidelines:

- Primary color: A vibrant light green (#90EE90) to instill calmness and focus. Evokes growth and trustworthiness for test preparation.
- Background color: A very light green (#E0F8E0), a desaturated variant of the primary green, to be easy on the eyes during long practice sessions.
- Accent color: A contrasting orange (#FF8F29), for important interactive elements like submit buttons and score highlights. Provides an energetic contrast to the primary green.
- Body and headline font: 'Inter' for a clean and modern sans-serif style suitable for both headers and body text. Provides good readability.
- Use clear and simple icons for the menu and key features. Ensure the icons are intuitive and aid navigation.
- A clean, structured layout that allows users to easily access tests, track scores, and navigate through the site. Minimize distractions.
